# FAQ-BOT
Developed an AI-powered FAQ chatbot using Python, Streamlit, Google Gemini API, ChromaDB, and PyPDF2. The application extracts text from PDF documents, creates semantic embeddings, stores them in a vector database, and answers user queries using Retrieval-Augmented Generation (RAG)

AI FAQ Assistant using RAG is a Generative AI application that enables users to interact with PDF documents through natural language. The system extracts document content, stores vector embeddings in ChromaDB, retrieves the most relevant context based on user queries, and generates accurate responses using the Google Gemini API. The project demonstrates practical implementation of Retrieval-Augmented Generation (RAG), vector databases, semantic search, and Large Language Models (LLMs)

# 🤖 FAQ Bot using Google Gemini & RAG

## 📌 Overview

This project is an AI-powered FAQ chatbot that answers user questions based on uploaded documents. It uses Google's Gemini API with Retrieval-Augmented Generation (RAG) to provide accurate, context-aware responses instead of relying only on the LLM's pre-trained knowledge.

## 🚀 Features

* 📄 Upload PDF documents
* 🔍 Extract and process text from PDFs
* 🧠 Generate embeddings
* 🗂️ Store embeddings in ChromaDB (Vector Database)
* 💬 Ask questions in natural language
* 🤖 Context-aware responses using Google Gemini
* ⚡ Fast semantic search
* 🌐 Interactive Streamlit web interface

## 🛠️ Tech Stack

* Python
* Streamlit
* Google Gemini API
* ChromaDB
* PyPDF2
* python-dotenv
* Vector Embeddings
* Retrieval-Augmented Generation (RAG)

## 📂 Project Workflow

1. Upload PDF documents.
2. Extract text from the PDF.
3. Split text into chunks.
4. Generate embeddings using Gemini.
5. Store embeddings in ChromaDB.
6. Perform semantic search for relevant chunks.
7. Send retrieved context with the user's question to Gemini.
8. Display an accurate answer in the Streamlit interface.
